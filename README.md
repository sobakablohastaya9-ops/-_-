# Агромониторинг Ставрополья

Аналитический дашборд по озимой пшенице для 26 муниципальных округов Ставропольского края: урожайность, погода, цены, маржа на гектар и риски.

Дашборд: https://sobakablohastaya9-ops.github.io/-_-/

## Данные
- Росстат, БД ПМО: посевная площадь и валовой сбор по округам, 2008-2025
- Open-Meteo (реанализ ERA5): погода по центрам округов, 2004-2026, климатическая норма 1991-2020
- ЕМИСС: цены производителей на пшеницу (57693) и цены на дизельное топливо (31448), по месяцам
- Северо-Кавказстат: индексы производства растениеводства

Подробно в SOURCES.md.

## Методы
- Линейный тренд урожайности по каждому округу, отклонения от тренда в %
- Панельная регрессия отклонений на погодные факторы (температура мая-июня, ГТК, осадки весны, осени и зимы, заморозки), фиксированные эффекты округов, стандартные ошибки кластеризованы по годам
- Отбор модели для прогноза по ретропрогнозу leave-one-year-out (MAPE): модель 11,5%, тренд 12,6%
- Диагностика: Шапиро-Уилк, Jarque-Bera, Бройша-Пагана, Дарбина-Уотсона, VIF, устойчивость коэффициентов в расширяющемся окне
- Кластеризация округов по профилю отклонений (Уорд), индекс Морана
- Цены: STL-разложение, сезонность и критерий Краскела-Уоллиса, распределение месячных изменений, паритет дизель/пшеница
- Маржа на гектар по технологической карте, факторный анализ изменения маржи, чувствительность
- Стресс-тест на исторических сезонах и Монте-Карло (4000 сценариев) для сезона 2027

## Структура
```
data/raw/      исходные выгрузки
data/clean/    таблицы округ x год
scripts/
  00_fetch_spring.py   выгрузка весенней погоды из Open-Meteo
  01_prepare.py        очистка и сведение данных
  02_analysis.py       модели и расчеты, результат в docs/data/agro.json
  04_datalens.py       CSV для Yandex DataLens
docs/          дашборд (HTML, CSS, JavaScript), публикуется через GitHub Pages
datalens/      CSV и инструкция для DataLens
```

Дашборд строит все графики в браузере из docs/data/agro.json. Переключатель "Текущие осадки" запрашивает осадки с 1 сентября по сегодняшний день из Open-Meteo.

## Запуск
```bash
pip install -r requirements.txt
python scripts/01_prepare.py
python scripts/02_analysis.py
python scripts/04_datalens.py
python -m http.server -d docs 8000
```

## Ограничения
- Погода объясняет около трети колебаний урожайности (R2 внутри округов 0,36)
- Погода берется по центру округа
- Затраты нормативные, по технологической карте
