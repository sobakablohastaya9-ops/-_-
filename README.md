# Агромониторинг Ставрополья

Аналитический дашборд для сельхозпроизводителя и банка: урожай озимой пшеницы, погода, цены и маржа на гектар по 26 муниципальным округам Ставропольского края.

**Дашборд:** https://sobakablohastaya9-ops.github.io/-_-/

## Что я сделала
1. Собрала открытые данные: урожайность по округам из БД ПМО Росстата (2008–2025), погоду по центрам округов из Open-Meteo (2004–2026) и климатическую норму 1991–2020, цены на пшеницу и дизель из ЕМИСС. Подробно — в [SOURCES.md](SOURCES.md).
2. Очистила и свела данные в таблицы «округ × год» (`scripts/01_prepare.py` → `data/clean/`).
3. Построила модели (`scripts/02_analysis.py`):
   - технологический тренд урожайности по каждому округу и отклонения от него;
   - панельная регрессия «погода → отклонение урожая» с фиксированными эффектами округов и ошибками, кластеризованными по годам;
   - проверка прогноза на прошлых годах (leave-one-year-out): модель по погоде ошибается в среднем на 11,5%, прогноз «только по тренду» — на 12,6%;
   - сезонность цены пшеницы (STL-разложение + критерий Краскела–Уоллиса) и паритет «дизель / пшеница»;
   - маржа на гектар по техкарте, стресс-тест «что если повторится погода 2010, 2020, 2024…» и Монте-Карло на 4000 сценариев для сезона 2027.
4. Сделала дашборд (`docs/`) — обычная веб-страница на HTML/CSS/JavaScript, графики рисуются в SVG. Переключатель «Живая погода» подтягивает текущие осадки из Open-Meteo прямо в браузере.
5. Подготовила CSV для DataLens (`scripts/04_datalens.py` → `datalens/`).

## Как повторить
```bash
pip install -r requirements.txt
python scripts/01_prepare.py
python scripts/02_analysis.py
python scripts/04_datalens.py
```
Открыть `docs/index.html` через локальный сервер: `python -m http.server -d docs 8000` → http://localhost:8000

## Структура
```
data/raw/      исходные выгрузки
data/clean/    очищенные таблицы
scripts/       код: 00 — выгрузка погоды, 01 — очистка, 02 — анализ, 04 — CSV для DataLens
docs/          дашборд (публикуется через GitHub Pages)
datalens/      данные и инструкция для резервной версии
```

## Ограничения
Погода объясняет примерно треть колебаний урожая (R² внутри округов 0,36): град, ливни в уборку, технологии хозяйств в открытых данных не видны. Поэтому модель — сигнал риска, а не точный прогноз. Затраты — нормативные (техкарта), а не фактические.
