# Источники данных

Дата выгрузки: октябрь 2026.

## Файлы в data/raw
- pmo_yields_by_district.txt - посевная площадь и валовой сбор озимой пшеницы и зерновых по 26 округам, 2008-2025. Урожайность = валовой сбор / посевная площадь, ц/га. Источник: Росстат, База данных показателей муниципальных образований, раздел 7 (https://rosstat.gov.ru/storage/mediabank/munst.htm). Выгрузка по краю из полной копии БД ПМО проекта "Если быть точным" (https://tochno.st/datasets).
- weather_part1.txt, weather_part2.txt - погода по сезонам для центра каждого округа, 2004-2026: осадки и ГТК мая-июня, заморозки, жаркие дни, осадки осени и зимы, температура. Источник: Open-Meteo Historical Weather API, реанализ ERA5 (https://open-meteo.com/en/docs/historical-weather-api).
- weather_norms_1991_2020.txt - климатическая норма тех же показателей, 1991-2020. Источник тот же.
- weather_spring.txt - весна 2004-2026: осадки марта-мая, температура апреля, заморозки, жаркие дни, суммы температур. Источник тот же, скрипт scripts/00_fetch_spring.py.
- weather_monthly_krai_2026.csv - осадки по месяцам 2026 года и норма, среднее по краю. Источник тот же.
- prices_wheat_sk_monthly.csv - средние цены производителей на пшеницу, Ставропольский край и РФ, руб./т. Источник: ЕМИСС, показатель 57693 (https://www.fedstat.ru/indicator/57693).
- diesel_retail_sk_monthly.csv - средние потребительские цены на дизельное топливо, Ставропольский край, руб./л. Источник: ЕМИСС, показатель 31448 (https://www.fedstat.ru/indicator/31448).

## Дополнительно
- Северо-Кавказстат: индексы производства растениеводства по округам, стоимость продукции, валовой сбор зерна (https://26.rosstat.gov.ru)
- Министерство сельского хозяйства Ставропольского края: оперативные данные уборки 2026 (https://www.mshsk.ru)
- Технологическая карта возделывания озимой пшеницы (direct.farm, 2023): затраты на гектар

## Примечания
- Георгиевский округ, 2014-2019: данные исключены, в эти годы показатели учитывались вместе с городом Георгиевском.
- В БД ПМО нет данных по округам за 2009 и 2012 годы.
- Росстат и ЕМИСС не отдают данные автоматическим запросам, эти файлы обновляются вручную.
