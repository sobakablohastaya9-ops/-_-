# Источники данных

Все данные открытые. Дата выгрузки — октябрь 2026.

| Файл в `data/raw/` | Что это | Источник |
|---|---|---|
| `pmo_yields_by_district.txt` | посевная площадь и валовой сбор озимой пшеницы и зерновых по 26 муниципальным округам, 2008–2025; урожайность = сбор / площадь, ц/га | Росстат, База данных показателей муниципальных образований (БД ПМО), раздел 7 «Сельское хозяйство» — https://rosstat.gov.ru/storage/mediabank/munst.htm . Выгрузка по Ставропольскому краю сделана из полной копии БД ПМО, которую публикует проект «Если быть точным» — https://tochno.st/datasets |
| `weather_part1.txt`, `weather_part2.txt` | погода по сезонам для центра каждого округа, 2004–2026: осадки и ГТК мая–июня, заморозки, жара, осадки осени и зимы, температура | Open-Meteo, Historical Weather API (реанализ ERA5) — https://open-meteo.com/en/docs/historical-weather-api |
| `weather_norms_1991_2020.txt` | климатическая норма тех же показателей, 1991–2020 | там же |
| `weather_spring.txt` | весна: осадки марта–мая, температура апреля, заморозки, жаркие дни, суммы температур; 2004–2026 | там же; повторить выгрузку — `python scripts/00_fetch_spring.py` |
| `weather_monthly_krai_2026.csv` | осадки по месяцам 2026 года и норма, в среднем по краю | там же |
| `prices_wheat_sk_monthly.csv` | средние цены производителей на пшеницу, Ставропольский край и РФ, руб./т, по месяцам | ЕМИСС, показатель 57693 — https://www.fedstat.ru/indicator/57693 |
| `diesel_retail_sk_monthly.csv` | средние потребительские цены на дизельное топливо, Ставропольский край, руб./л, по месяцам | ЕМИСС, показатель 31448 — https://www.fedstat.ru/indicator/31448 |

Дополнительно (цифры перенесены в дашборд вручную, в карточки «Пульс края»):
- Северо-Кавказстат — индексы производства продукции растениеводства по округам, стоимость продукции, валовой сбор зерна по краю — https://26.rosstat.gov.ru
- Министерство сельского хозяйства Ставропольского края, новости о ходе уборки 2026 — https://www.mshsk.ru
- Технологическая карта возделывания озимой пшеницы (direct.farm, 2023) — затраты на гектар для модели маржи.

Ограничения:
- Росстат и ЕМИСС не отдают данные автоматическим запросам с зарубежных серверов, поэтому эти файлы обновляются вручную раз в год / в месяц.
- По Георгиевскому округу данные 2014–2019 исключены: в эти годы показатели учитывались вместе с городом Георгиевском (объединение муниципалитетов).
- В БД ПМО нет данных по округам за 2009 и 2012 годы.
