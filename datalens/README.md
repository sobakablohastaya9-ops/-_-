# Данные для Yandex DataLens

CSV в кодировке UTF-8, разделитель запятая. Формируются скриптом scripts/04_datalens.py.

- 01_okruga.csv - показатели 26 округов: зона, площадь, урожайность 2025, волатильность, отклонение 2020, осадки осени 2026, вероятность убытка 2027, маржа
- 02_urozhaj_po_godam.csv - урожайность, тренд и отклонение от тренда по округам и годам
- 03_marzha_kraja.csv - урожайность, цена, затраты и маржа на гектар по краю по годам
- 04_ceny_mesyac.csv - цена пшеницы по месяцам и паритет дизель/пшеница
- 05_stress_test.csv - урожайность и маржа округов по сценариям стресс-теста
